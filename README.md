# Spam Neuron Simulator

Beginner-friendly one-neuron simulator for the video "How Does AI Actually Learn? From Neural Networks to Hallucinations" (Decode It with Vic). Adjust the weights for *prize, money, dear, win, hello* plus the bias, and watch z, the sigmoid probability and the FLAGGED verdict change.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`

Deploy: push to GitHub, then at share.streamlit.io choose New app, pick this repo, branch `main`, main file `app.py`, Deploy.

Math source: Lee, Fangfang. "What Is a Neural Network?" IBM Think.
